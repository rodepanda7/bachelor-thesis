\chapter{Call-by-box Lambda Calculus }

This chapter introduces the call-by-box lambda calculus (\lab), which is a refinement of another \lc, \labox \cite{espritosanto_et_al:LIPIcs:2019:10525}.
The calculus \labox is a fragment of Bierman and de Paiva's \textsf{IS4} \cite{BiermanPaiva2000}.
The fragment is so restricted that all typing rules are quite simple.
