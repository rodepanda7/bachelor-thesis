\section{\texorpdfstring{Specification of \boldmath${\la_b}$}{ Specification of the call-by-box lambda calculus}}

\subsection{Intuitionistic logic \textsf{IS4}}
Intuitionistic modal logic \textsf{IS4} is a non-classical logic that is based on the idea of constructive proof.
Unlike classical logic, intuitionistic logic does not allow for the law of excluded middle, which states that for every proposition $P$,
the statement $P \lor \neg P$ is assumed \cite{Heyting1930, sep-intuitionistic-logic-development}.
In intuitionistic logic, a proposition is only considered true if it can be constructively proven.
That is, a proposition is true if we can explicitly construct a proof, much like writing a program.
This is why programming languages and proofs in systems like Agda and Rocq are based on intuitionistic logic.
Since \lc is the foundation of functional programming, it corresponds with intuitionistic logic via the Curry-Howard correspondence,
where programs are equivalent to proofs and types to propositions \cite{Howard1980}.

The intuitionistic modal logic \textsf{IS4} is an extension of intuitionistic logic that introduces the \emph{modal operator} $\square$.
The term calculus \labox is a fragment of \textsf{IS4} that, besides the usual \lterms, also uses box ($\mathsf{box}$) and unbox ($\varepsilon$) operators 
and is strong enough to interpret both call-by-name (\textsf{cbn}) and call-by-value (\textsf{cbv}) lambda calculi \cite{espritosanto_et_al:LIPIcs:2019:10525}.
The box is like a container that delays a computation, making it possible to simulate both \textsf{cbn} and \textsf{cbv} evaluation strategies.
Espírito Santo et al. refined this calculus to a simpler calculus, which they call the \emph{call-by-box \lc} (\lab). 
This refinement has simpler typing rules and only one \br rule.
In this thesis, we formalize \lab in Agda.

\subsection{\texorpdfstring{Terms and Types of \boldmath${\la_b}$}{ Terms and Types of the boxed lambda calculus}}
We now define the types of the \lab calculus as is done in \cite{espritosanto_et_al:LIPIcs:2019:10525}. We indicate the types of \lab with $A$ and $B$, representing types and boxed types respectively.
The type $X$ denotes the base type. Note that functions types are of the form $B \fa A$ thus the input is always a boxed type.

\begin{definition}
  \label{def:typesb}
  \textbf{Types of \boldmath${\la_b}$} are given via the following grammar:
	\begin{align*}
    \begin{grammar}{
      \pr{$A$}{$X \gors B \fa A \gors B$}
    } \quad \quad
    \end{grammar}
    \begin{grammar}{
      \pr{$B$}{$\boxit{A}$}
    }
    \end{grammar}
  \end{align*}
\end{definition}


We give some examples of types in \lab. Note that $A$ can be any type that is not boxed, while $B$ can be any type that is boxed. 
The type $X$ is the base type. 

\begin{example}
  \label{ex:typesb}
  \textbf{Types in \boldmath${\la_b}$:}
  \begin{align*}
    & X \\
    & \boxt{(B \fa A)} \\
    & \boxt{X} \fa X \\
    & \boxt{A} \fa \boxt{B} \\
    & \boxt{\boxt{\boxt{X}}} \fa \boxt{X}
  \end{align*}
\end{example}

Since variables are always boxed in \lab, they always occur inside the unboxing operator $\varepsilon$.
Thus, we only have $\boxe{x}$ in the grammar with $x$ a variable.
Abstractions in \lab, take boxed terms as arguments, which is why we define abstractions as $\lamb{x}{M}$, where $x$ is the parameter of a boxed type and $M$ is a term.
The rest of the terms are defined in \cref{def:lab} and some example terms are given in \cref{ex:termsb}.
In this thesis, we use $M$, $N$, $P$, and $Q$ for arbitrary terms in \lab.

\begin{definition}
  \label{def:lab}
  \textbf{Terms in \boldmath${\la_b}$} are given by:
  \begin{align*}    
    \begin{grammar}{
      \pr{$M, N, P, Q$}{$\boxe{x} \gors \lambda x.M \gors M N \gors \boxi{N}$}
    }
    \end{grammar}
  \end{align*}
\end{definition}

\begin{example}
  \label{ex:termsb}
  \textbf{Terms in \boldmath${\la_b}$:}
  \begin{align*}
    & \boxe{x} \\
    & \lamb{x}{\boxe{x}} \\
    & (\lamb{x}{\boxe{x}}) \boxi{\boxe{y}} \\
    & (\lamb{x}{\boxe{x}}) \boxi{\lamb{y}{\boxe{y}}}
  \end{align*}
\end{example}

The typing rules of \lab are defined in \cref{def:typing-rulesb} and are identical to the typing rules in \cite{espritosanto_et_al:LIPIcs:2019:10525}. The $\square$-I rule states that if $M$ is of type $A$, then $\boxi{M}$ is of type $\boxt{A}$.
The Id$_\square$ rule is the identity rule for boxed variables, which states that if we know that $x$ is a variable of type $\boxt{A}$, we can conclude that $\boxe{x}$ is of type $A$.
The only way to add variables to the context is by using the \impliesi rule. These variables are always boxed, since they are the parameters of abstractions.
Due to the grammar of \lab, all variables in \lab occur inside the unboxing operator $\varepsilon$ and thus the Id$_\square$ rule covers all cases.
The \impliese rule states that if we have a term $M$ of type $B \fa A$ and a term $N$ of type $B$, we can conclude that the application $M N$ has type $A$.
It is important that the argument $N$ is a boxed term, which is why we denote its type as $B$.

\begin{definition}
  \label{def:typing-rulesb}
  \textbf{Typing rules of \boldmath${\la_b}$} are defined as follows:
  \begin{prooftree}
    \def\extraVskip{5pt}
    \AxiomC{\phantom{A}}
    \RightLabel{Id$_\square$}
    \UnaryInfC{$\judgement{\Gamma, x : \boxt{A}}{\boxe{x} : A}$} % Conclusion
  \end{prooftree}
  
  \begin{prooftree}
    \def\extraVskip{5pt}
    \AxiomC{$\judgement{\Gamma, x : A}{M : B}$}
    \RightLabel{\impliesi}
    \UnaryInfC{$\judgement{\Gamma}{\lamb{x}{M} : A \fa B}$} % Conclusion
  \end{prooftree}
  
  \begin{prooftree}
    \def\extraVskip{5pt}
    \AxiomC{$\judgement{\Gamma}{M : B \fa A}$}
    \AxiomC{$\judgement{\Gamma}{N : B}$}
    \RightLabel{\impliese}
    \BinaryInfC{$\judgement{\Gamma}{M N : B}$} % Conclusion
  \end{prooftree}
  
  \begin{prooftree}
    \def\extraVskip{5pt}
    \AxiomC{$\judgement{\Gamma}{M : A}$}
    \RightLabel{$\square$-I}
    \UnaryInfC{$\judgement{\Gamma}{\boxi{M} : \boxt{A}}$} % Conclusion
  \end{prooftree}
\end{definition}

We now demonstrate these typing rules with \cref{ex:typingb}, where we show that the term $(\lamb{x}{\boxe{x}}) \boxi{\lamb{y}{\boxe{y}}}$ is well-typed. 
Note that the argument $\boxi{\lamb{y}{\boxe{y}}}$ is boxed. 
If the argument was not boxed, we would not be able to apply the abstraction $\lamb{x}{\boxe{x}}$ to it.

\begin{example}
  \label{ex:typingb}
  \textbf{Well-typedness of \boldmath$(\lamb{x}{\boxe{x}}) \boxi{\lamb{y}{\boxe{y}}}$.} The typing derivation of \lterm $(\lamb{x}{\boxe{x}}) \boxi{\lamb{y}{\boxe{y}}}$ is given by the tree below.
  \small
  \begin{prooftree}
    \def\extraVskip{5pt}
        \AxiomC{\phantom{A}}
      \RightLabel{Id$_\square$}
      \UnaryInfC{$\judgement{x : \boxt{(\boxt{A} \fa A)}}{\boxe{x} : \boxt{A} \fa A}$}
    \RightLabel{\impliesi}
    \UnaryInfC{$\judgement{}{\lamb{x}{\boxe{x}} : \boxt{(\boxt{A} \fa A)} \fa (\boxt{A} \fa A)}$}
    
        \AxiomC{\phantom{A}}
        \RightLabel{Id$_\square$}
        \UnaryInfC{$\judgement{y : \boxt{A}}{\boxe{y} : A}$}
      \RightLabel{\impliesi}
      \UnaryInfC{$\judgement{}{\lamb{y}{\boxe{y} : \boxt{A} \fa A}}$}
    \RightLabel{$\square$-I}
    \UnaryInfC{$\judgement{}{\boxi{\lamb{y}{\boxe{y}}} : \boxt{(\boxt{A} \fa A)}}$}
    \RightLabel{\impliese}
    \BinaryInfC{$\judgement{}{(\lamb{x}{\boxe{x}}) \boxi{\lamb{y}{\boxe{y}}} : \boxt{A} \fa A}$} % Conclusion
  \end{prooftree}
\end{example}


\section{\texorpdfstring{Substitution in ${\la_b}$}{ Substitution in the boxed lambda calculus}}

Since variables always occur inside $\varepsilon$, we need to redefine free and bound variables and substitution.
For \lab, we have: 

\begin{definition}
  \label{def:fv}
  \textbf{Free and Bound Variables} in \lab are defined as follows:
  \begin{align*}
    & FV_b(\boxe{x})    & &= \{x\}                          & & BV(\boxe{x})    & &= \emptyset \\
    & FV_b(\lamb{x}{M}) & &= FV(M) \backslash \{x\}         & & BV(\lamb{x}{M}) & &= BV(M) \cup \{x\} \\
    & FV_b(M N)         & &= FV(M) \cup FV(N)               & & BV(M N)         & &= BV(M) \cup BV(N)
  \end{align*}
\end{definition}

\begin{definition}
  \label{def:subst}
  \textbf{Substitution in \lab} of some \lterm $Q$ for an unboxed variable $\boxe{x}$ in some \lterm is defined by:
  \[
\begin{aligned}
	& \boxe{x} \subst{\boxe{x}}{Q}            & &= Q \\
	& \boxe{y}  \subst{\boxe{x}}{Q}           & &= \boxe{y} \text{ if } (x \neq y)\\
  & \boxi{M} \subst{\boxe{x}}{Q}            & &= \boxi{M \subst{\boxe{x}}{Q}} \\
	& (M N) \subst{\boxe{x}}{Q}               & &= M \subst{\boxe{x}}{Q} N \subst{\boxe{x}}{Q} \\
	& (\lamb{x}{M}) \subst{\boxe{x}}{Q}       & &= \lamb{x}{M} \\
	& (\lamb{y}{M}) \subst{\boxe{x}}{Q}       & &= \lamb{z}{M \subst{\boxe{y}}{\boxe{z}}\subst{\boxe{x}}{Q}} \text{ if } (x \neq y) \\
\end{aligned}
\]
with $z$ a variable defined by:
\begin{enumerate}
	\item%1
	If $x \notin FV_b(Q)$ or $y \notin FV_b(M)$ then $z = y$
	\item%2
	Otherwise, $z$ can be any variable such that $z \notin FV(Q)$ or $z \notin FV(M)$
\end{enumerate}
\end{definition}

With this new \lc, it may not be completely clear that substitution preserves well-typedness.
We can prove that substitution preserves well-typedness in \lab.
\begin{proposition}
  \textbf{Preservation of well-typedness in \boldmath${\la_b}$:}
  \[
    \mbox{If } \judgement{\Gamma, x : \boxt{A}}{M : A'} \mbox{ and } \judgement{\Gamma}{Q : A} \mbox{ then } \judgement{\Gamma}{M \subst{\boxe{x}}{Q} : A'}
  \]
\end{proposition}

\begin{proofthm}
  \textbf{Preservation of well-typedness in \boldmath${\la_b}$}. We prove by structural induction on the term $M$ that this substitution preserves well-typedness.
  \begin{enumerate}
    \item%1 
    We now prove:
    \[
      \mbox{If } \judgement{\Gamma, x : \boxt{A}}{\boxe{x} : A'} \mbox{ and } \judgement{\Gamma}{Q : A} \mbox{ then } \judgement{\Gamma}{\boxe{x} \subst{\boxe{x}}{Q} : A'}
    \]
    From the assumption, we have that $\judgement{\Gamma, x : \boxt{A}}{\boxe{x} : A'}$.
    It follows that $x : \boxi{A}$ and thus $\boxe{x} : A$. We get that $A = A'$. 
    Now, it follows that $\judgement{\Gamma}{M \subst{\boxe{x}}{Q} : A'}$ since $\boxe{x} \subst{\boxe{x}}{Q} = Q$.
    \item%2
    We now prove:
    \[
      \mbox{If } \judgement{\Gamma, x : \boxt{A}}{\boxe{y} : A'} \mbox{ and } \judgement{\Gamma}{Q : A} \mbox{ then } \judgement{\Gamma}{\boxe{y} \subst{\boxe{x}}{Q} : A'}
    \]
    We have that $\boxe{y} \subst{\boxe{x}}{Q} = \boxe{y}$, so $\judgement{\Gamma}{\boxe{y} \subst{\boxe{x}}{Q} : A'}$.    
    \item%3
    We now prove:
    \[
      \mbox{If } \judgement{\Gamma, x : \boxt{A}}{\boxi{M} : A'} \mbox{ and } \judgement{\Gamma}{Q : A} \mbox{ then } \judgement{\Gamma}{\boxi{M} \subst{\boxe{x}}{Q} : A'}
    \]
    Let $M$ be of type $A''$ ($A' = \boxit{A''}$). By the induction hypothesis, we get that $\judgement{\Gamma}{M \subst{\boxe{x}}{Q} : A''}$.
    It follows that $\boxi{M \subst{\boxe{x}}{Q}} : \boxit{A''}$ or $\boxi{M \subst{\boxe{x}}{Q}} : A'$.
    Since $\boxi{M} \subst{\boxe{x}}{Q} = \boxi{M \subst{\boxe{x}}{Q}}$, we get $\judgement{\Gamma}{\boxi{M} \subst{\boxe{x}}{Q} : A'}$ 
    \item%4
    We now prove:
    \[
      \mbox{If } \judgement{\Gamma, x : \boxt{A}}{M N : A'} \mbox{ and } \judgement{\Gamma}{Q : A} \mbox{ then } \judgement{\Gamma}{M N \subst{\boxe{x}}{Q} : A'}
    \]
    Let $N$ be of type $A''$. We get that $M$ has type $A'' \fa A'$ because of the typing rule \impliese.
    By induction, we get: 
    \begin{center}  
    $\judgement{\Gamma}{M \subst{\boxe{x}}{Q}} : A'' \fa A'$ and $\judgement{\Gamma}{N \subst{\boxe{x}}{Q}} : A''$
    \end{center}
    Since $M N \subst{\boxe{x}}{Q} = M \subst{\boxe{x}}{Q} N \subst{\boxe{x}}{Q}$, and \\
    $M \subst{\boxe{x}}{Q} N \subst{\boxe{x}}{Q} : A'$, we get
    $\judgement{\Gamma}{M N \subst{\boxe{x}}{Q} : A'}$.
    \item%5
    We now prove:
    \[
      \mbox{If } \judgement{\Gamma, x : \boxt{A}}{\lamb{x}{M} : A'} \mbox{ and } \judgement{\Gamma}{Q : A} \mbox{ then } \judgement{\Gamma}{\lamb{x}{M} \subst{\boxe{x}}{Q} : A'}
    \]
    We have that $\lamb{x}{M} \subst{\boxe{x}}{Q} = \lamb{x}{M}$, since $x$ is a bound variable in $\lamb{x}{M}$.
    It immediately follows that $\judgement{\Gamma}{\lamb{x}{M} \subst{\boxe{x}}{Q} : A'}$.
    \item%6
    We now prove:
    \[
      \mbox{If } \judgement{\Gamma, x : \boxt{A}}{\lamb{y}{M} : A'} \mbox{ and } \judgement{\Gamma}{Q : A} \mbox{ then } \judgement{\Gamma}{\lamb{y}{M} \subst{\boxe{x}}{Q} : A'}
    \]
    Let $x \neq y$, $A' = B \fa A''$, $y$ be of type $\boxit{B}$ and $M$ be of type $A''$.
    By induction, we get the following with $z$ a fresh variable defined by the rules in \cref{def:subst}:
    \[
      \judgement{\Gamma}{M \subst{\boxe{y}}{\boxe{z}} : A''} \mbox{ and } \judgement{\Gamma}{M \subst{\boxe{y}}{\boxe{z}}\subst{\boxe{x}}{Q} : A''}
    \]

    From $\judgement{\Gamma}{M \subst{\boxe{y}}{\boxe{z}}\subst{\boxe{x}}{Q} : A''}$ it follows that \\
    $\judgement{\Gamma}{\lamb{y}{M} \subst{\boxe{y}}{\boxe{z}}\subst{\boxe{x}}{Q} : B \fa A''}$, since $y$ is op type $B$.
    From this, the following statement follows: 
    \[
      \lamb{y}{M} \subst{\boxe{x}}{Q} = \lamb{z}{(M \subst{\boxe{y}}{\boxe{z}}\subst{\boxe{x}}{Q})}
    \] 
    Now, we conclude $\judgement{\Gamma}{\lamb{y}{M} \subst{\boxe{x}}{Q} : A'}$. $\square$
  \end{enumerate}
  % \renewcommand{\qedsymbol}{}
\end{proofthm}

With this definition of substitution, we define the reduction rule for \lab in \cref{def:beta}.
In \lab, the arguments of abstractions are always boxed, so we can only apply abstractions to boxed terms.
Since variables only occur insides $\varepsilon$, we can replace those, including $\varepsilon$, with the corresponding unboxed term.

\begin{definition}
  \label{def:beta}
  \textbf{\boldmath${\beta}$-reduction} in \lab is defined as follows:
  \begin{align*}
    (\lamb{x}{M})\boxi{N} \red M \subst{\boxe{x}}{N} \quad \quad (\bb)
  \end{align*}
\end{definition}

For completeness, we need to define a new closure rule. This new rule only applies to the \lab, and allows reduction under boxed terms.
We call this rule $\zeta$, and \cref{def:closure} defines it.

\begin{definition}
  \label{def:closure}
  \textbf{The closure rule \boldmath${\zeta}$.} This rule allows reduction under boxed terms in \lab.
  \begin{prooftree}
    \def\extraVskip{5pt}
    \AxiomC{$M \redbbox N$}
    \RightLabel{($\zeta$)}
    \UnaryInfC{$\boxi{M} \redbbox \boxi{N}$} % Conclusion
  \end{prooftree}
\end{definition}

The relations defined here are from \cite{espritosanto_et_al:LIPIcs:2019:10525} and form the reduction and evaluation relations of \lab.
The relation $\redbbox$ allows reduction under all term formers, including boxes. 
We also define three other relations: $\bb$ closed under $\mu$ and $\nu$, $\bb$ closed under $\mu$ and $\bb$ closed under $\nu$.
We call them $\redwe$, $\redbn$ and $\redbv$ respectively. \Cref{tab3:closure-rules} is an overview of all relations.  
The relation $\redwe$ is weak since values do not reduce.
That is, abstractions and terms of the form $\boxe{x}$ do not reduce.
The relation $\redwe$ is also external as boxes do not reduce. This relation is called call-by-box (cbb) evaluation.
We will see after defining the embeddings that $\redwe$ collapses to $\redbn$ in Girard's embedding and that $\redwe$ collapses to $\redbv$ in Gödel's embedding.
