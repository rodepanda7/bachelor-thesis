\section{Overview of the Formalisation}
\label{sec:overview-formalisation}

This section provides an overview of the formalisation in Agda.
We show how propositions in \cref{sec:name-embedding} and \cref{sec:value-embedding} are formalised in Agda.
We also give the main helper lemmas that are needed to prove these propositions.
The formalisation is available on GitHub and archived on Zenodo \cite{floris_reuvers_2025_15743863} \footnote{\noindent Link to GitHub: \url{https://github.com/rodepanda7/call-by-box}. \\ Link to Zenodo: \url{https://doi.org/10.5281/zenodo.15743863}}.


\subsection{File Structure}
\label{sec:file-structure}
The Agda formalisation is structured into a number of files. Here, we go over the file structure.
The project has the following three main directories: \texttt{examples}, \texttt{formalisation} and \texttt{proofs}.
The \texttt{examples} directory contains some examples of \lterms, substitution, embeddings and reductions.
The \texttt{formalisation} directory is the most important directory and contains the formalisation of \lterms, substitution, embeddings and reductions.
Here, we list all files in this directory and give a short description of their contents:
\begin{itemize}
  \item \texttt{boxCalc.agda}: Contains the definition of \lterms in \lab, the definition of substitution and the definition of values in \lab.
  \item \texttt{boxCalcRed.agda}: Contains all the reduction relations in \lab.
  \item \texttt{calc.agda}: Contains the definition of \lterms in the standard \lc, the definition of substitution and the definition of values.
  \item \texttt{embedCBNIntoCBB.agda}: Contains the definition of Girard's embedding.
  \item \texttt{embedCBVIntoCBB.agda}: Contains the definition of Gödel's embedding.
  \item \texttt{nameCalcRed.agda}: Contains the reduction relations for \lan.
  \item \texttt{valueCalcRed.agda}: Contains the reduction relations for \lav.
\end{itemize}

The \texttt{proofs} directory contains the proofs of the propositions in \cref{sec:name-embedding} and \cref{sec:value-embedding} in the files \texttt{nameProofs.agda} and \texttt{valueProofs.agda} respectively.
Both files also contain all helper lemmas necessary to prove the propositions.

\subsection{Main Propositions in Agda}
\label{sec:proofs-main-propositions}
This subsection gives the propositions about Girard's and Gödel's embedding in Agda.
We do not give the proofs of these propositions, but they can be found in the Agda formalisation in the \texttt{proofs} directory.
We start with the propositions about Girard's embedding, and then we give the propositions about Gödel's embedding.
The first proposition, \cref{prop:girard-preservation-red}, states that Girard's embedding preserves reduction.
That is, if we have a \lterm $M$ and we reduce it to $N$ in \lan, then the translation of $M$ under Girard's embedding also reduces to the translation of $N$ under Girard's embedding. 
We repeat the proposition here for convenience:
\begin{center}
 For all \lterm $M$ and $N$, if $M \rednb N$ in \lan, then $\girard{M} \redbbox \girard{N}$.
\end{center}
\Cref{proof:girard-preservation-red} shows the proposition in Agda.
The proof is given in \texttt{proofs/nameProofs.agda}.
We made use of \cref{lem:girard-pres-subst} to prove this proposition.

  \label{proof:girard-preservation-red}
  \textbf{Preservation of reduction under Girard's translation.} 
  \small

\end{proposition}

The second proposition about Girard's translation is \cref{prop:girard-preservation-eval}.
It states that if a \lterm $M$ evaluates to $N$ in \lan with the relation $\redn$, 
then the translation of $M$ under Girard's embedding also evaluates to the translation of $N$ under Girard's embedding with $\redbn$.
Again, we repeat the proposition here for convenience:

\begin{center}
 For all \lterm $M$ and $N$, if $M \redn N$ in \lan, then $\girard{M} \redbn \girard{N}$.
\end{center}

\Cref{proof:girard-preservation-eval} shows the proposition in Agda.
The proof is similar to the proof of \cref{proof:girard-preservation-red} and is given in \texttt{proofs/nameProofs.agda}.
The only difference is that we have fewer cases for the evaluation relation $\redn$ and thus the proof is shorter.

The next two propositions are about Gödel's embedding.
The first proposition of Gödel's embedding we proved is \cref{prop:godel-preservation-red}.
It states if a \lterm $M$ in \lav reduces to $N$ in one step, then $\godel{M}$ reduces to $\godel{N}$ in \lab in two steps.
We repeat the proposition here for convenience:
\begin{center}
 For all \lterms $M$ and $N$, if $M \rednb N$ in \lav, then $\godel{M} \redbboxt \godel{N}$.
\end{center}
\Cref{proof:gogel-preservation-2step-red} shows the Agda type of this proposition.
The proof makes use of a helper lemma that states that reduction is preserved after renaming a \lterm.
That is, if a \lterm $M$ reduces to $N$ in two steps, then $\textsf{renameb } fb' \ M$ also reduces to $\textsf{renameb } fb' \ N$ in two steps.
We do not go into detail about this lemma, but it can be found in \texttt{proofs/valueProofs.agda}.

\end{proposition}

The last proposition we proved is \cref{prop:godel-preservation-red}.
It states that if $M \redvb N$ in \lav, then $\godel{M} \redbboxts \godel{N}$.
We repeat the proposition here for convenience:
\begin{center}
 For all \lterms $M$ and $N$, if $M \redvb N$ in \lan, then $\godel{M} \redbboxts \godel{N}$.
\end{center}
The proof of this proposition is similar to the proof of \cref{proof:gogel-preservation-2step-red} and is given in \texttt{proofs/valueProofs.agda}.
Again, we make use of a helper lemma. The helper lemma states that if a \lterm $M$ reduces to $N$ with $\redbboxts$, then $\textsf{renameb } fb' \ M$ also reduces to $\textsf{renameb } fb' \ N$ with $\redbboxts$.
The proof of this lemma can also be found in \texttt{proofs/valueProofs.agda}.
